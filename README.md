# 3D 字牌生成器（Bambu P2S + AMS）

這個儲存庫包含可直接在瀏覽器使用的字牌生成器。

## 功能
- 自訂底板、外框、文字顏色
- 21 mm、60 mm 或自訂尺寸
- 齊平字與向右升高 10° 的實心凸字
- 鑰匙圈吊孔位置與合併排版
- 產生可由 Bambu Studio 匯入的 3MF（使用前請確認 AMS 耗材分色）

## 網站發布
在 GitHub **Settings → Pages → Build and deployment**，選擇 **Deploy from a branch**，Branch **main**、Folder **/(root)**，按 **Save**。

發布網址預期為：https://meako0703.github.io/3D_01/

網站的所有模型運算均在使用者自己的瀏覽器中進行。請先在 Bambu Studio 檢查小尺寸筆畫與分色切片；此工具尚未經全面實機驗證。
